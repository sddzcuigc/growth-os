# 成长森林 V25：恢复完整应用与原有功能

2026-10-21。V24 把只读课程总览当成了主要查看入口，并删掉奖励、连续成长、徽章展示，部分平板宽度还隐藏了树。本版修复这些问题，保留原版功能、已有孩子记录和 V23 的多端同步协议。

## 打开完整应用

Windows 双击 **启动成长森林.cmd**。需要 Node.js 22.13 以上，首次会安装工程依赖，然后打开 http://127.0.0.1:8787/ 。首次可选择“暂时只在本机使用”；本机记录保存在浏览器中。关闭终端后服务停止，重新双击即可继续。

**不要把 docs/技能树总览.html 当作产品。** 它是一份可离线阅读的课程资料，不会保存练习、项目或账号数据。直接用文件方式打开 index.html 会显示启动说明，避免展示无法执行模块的空界面。

本机服务器用于本地操作与开发，数据库与线上部署独立，不等同于已经发布的跨设备云端服务。线上预览仍使用同一 GitHub 草稿 PR，生产网站未发布。

## 恢复内容

- 首页恢复蓝／红技能果实、金银铜光环、下一份奖励、连续成长、成长徽章和连击显示。
- 添加技能、种树、导出备份、账号与同步入口放在主视觉之前。
- 所有宽度显示所有树；每棵树可以展开全部技能，超过四个技能也能直接练习。
- 连续天数按有日期的实际练习足迹计算；奖励进度与徽章使用已有记录，不编造连续六天或已解锁数量。
- 登录注册、家庭管理、家长确认、每日宝箱、周目标、备份恢复、PWA、路线与项目沿用已有处理，不删除或重置数据。

72 项具体技能、11 条路线和 8 个真实项目继续保留。孩子通过小技能的学习与复习，在真实项目里组合、应用和检验能力，获得成就感。
