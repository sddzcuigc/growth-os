# 成长森林：通用技能与职业路线

核对日期：2026-10-20。根据教育框架、职业任务与当前趋势构建的可修订路线；不是对未来职业的确定预测，也不要求每个孩子学完所有路线。

来源核对后的原创练习设计，尚未通过真实儿童教学效果验证。参考来源不等于本卡获机构认证。不存在对所有年龄、任务和情境都普遍最好的单一学习法。先示范、自己尝试、具体反馈、延后复习、换情境应用作为可调整起点。

## 生活与自理

### 按指定单位量取一份材料

编号：life-measure；前置：无。

准备：适合的量杯或秤、水或其他安全材料、目标数量。

1. 读清目标数量及单位，例如 200 毫升水。
2. 选择匹配的量杯或秤，辨认刻度。
3. 放稳容器并按工具说明归零或读初始值。
4. 缓慢加入材料，在正确位置读数并调整。
5. 再量一次比较差异，记录实际数值与工具精度。

检验：记录包含数值和单位；读数方法与工具匹配且能够重复。

练习：先看一次完整示范，再自己做，指出卡住的具体步骤。收起步骤后独立复现，对照完成条件找出差异，再练最小的出错步骤。换一种材料、题目或真实项目再次使用，记录需要的帮助。

成人支持：只使用适龄安全材料与工具，不把毫升和克直接当成相同单位。

### 在预算内选择一份采购方案

编号：life-budget；前置：为一道菜列采购清单、先估算再核算一次采购总价。

准备：模拟购物清单、预算额度、价签。

1. 写清总预算和必须买的东西。
2. 估算并核算清单总价。
3. 把超过预算的部分标出来。
4. 比较减少数量、替换商品和放弃非必需项的结果。
5. 写出最终选择并保留一点余量，核查总额没有超出。

检验：方案总额不超过预算；能说明保留与放弃的理由。

练习：先看一次完整示范，再自己做，指出卡住的具体步骤。收起步骤后独立复现，对照完成条件找出差异，再练最小的出错步骤。换一种材料、题目或真实项目再次使用，记录需要的帮助。

### 用小票核对金额和找零

编号：life-receipt；前置：先估算再核算一次采购总价。

准备：模拟小票、模拟付款金额、纸笔。

1. 把小票商品与实际清单逐项配对。
2. 检查数量、单价与单项金额。
3. 重新计算总金额。
4. 用付款金额减总金额，算出应找零金额。
5. 比较实际找零，发现差异时清楚提出核对请求。

检验：至少一次总金额和找零独立算对；能指出具体哪一项有差异。

练习：先看一次完整示范，再自己做，指出卡住的具体步骤。收起步骤后独立复现，对照完成条件找出差异，再练最小的出错步骤。换一种材料、题目或真实项目再次使用，记录需要的帮助。

成人支持：先用模拟付款练习；真实支付由照看者安排，不公开收付款码。

### 比较一次用量并减少一项浪费

编号：life-resource；前置：无。

准备：安全的日常任务、纸笔或量杯。

1. 选一次可观察任务，例如清洗用具或整理食材。
2. 记录原来用了多少水或材料及如何测量。
3. 找出一项不影响清洁或安全的可减少步骤。

### 把购物袋口系牢

编号：life-bag；前置：无。

准备：干净的空购物袋、少量不易碎的物品。

### 把番茄和鸡蛋炒熟并装盘

编号：life-cook；前置：按菜谱完成一次备料。

1. 按菜谱准备并检查灶具周围。

### 把一段操作说明变成行动清单

编号：learn-readsteps；前置：无。

准备：一段五至八句的适龄说明、纸笔。

### 先估算再核算一次采购总价

编号：learn-estimate；前置：无。

准备：三种模拟商品价签、纸笔、计算器。

1. 记下每种商品的单价和数量。
2. 把价格取便于心算的近似数，先估总额。
3. 逐项计算准确金额并求和。
4. 比较估算和准确金额的差距。
5. 说明误差来自哪里，再换一组价格试一次。

检验：准确总额可以复算；能够解释估算适合快速检查而非最终结账。

练习：先看一次完整示范，再自己做，指出卡住的具体步骤。收起步骤后独立复现，对照完成条件找出差异，再练最小的出错步骤。换一种材料、题目或真实项目再次使用，记录需要的帮助。

### 把一个目标拆成可练习的小步骤

编号：learn-breakdown；前置：无。

准备：一个自己想做的目标、纸笔。

1. 写下最后想做成的具体东西。
2. 列出完成它需要的动作。
3. 把仍然不知道如何开始的动作继续拆小。

## 真实项目

### 为家人准备一顿午餐

调用技能：为一道菜列采购清单、比较两种商品的单位价格、按清单完成一次买菜、把购物袋口系牢、按菜谱完成一次备料、把番茄和鸡蛋炒熟并装盘、做一次有依据的项目复盘。

1. 与家人确定一道菜、人数与可承担步骤。
2. 列清单、比较价格，和照看者完成采购。
3. 先练不会的具体动作，再完成备料与烹饪。
4. 展示实际做成的菜，区分自己与成人完成部分。
5. 保存清单和结果，复盘下次想独立完成哪一步。

成果：菜品结果、采购清单、自己使用过的技能和一次复盘。

成人全程负责刀具、灶火、热油等不适合孩子独立完成的环节。

### 做一份身边植物观察小册

调用技能：把一个目标拆成可练习的小步骤、追溯一条说法的原始来源、合上资料回答三个关键问题、整理文件并验证一份备份、展示作品并回答一个追问。

1. 选两三种常见植物和一个想回答的问题。
2. 记录现场观察，不采食不认识的植物。
3. 查找并核对名称来源，标明不确定。
4. 整理成含图、文字和来源的小册。
5. 向家人展示并回答一个追问。

成果：可阅读的小册、来源和仍不确定的问题。

### 做一个家里能使用的采购清单网页

调用技能：做一个有标题和表单的网页、让同一页面适配手机和电脑、给清单页面添加校验和操作、保存清单并验证刷新后仍在、为一个用户流程写三条测试、提交并说明一次可回退的修改、核对 AI 回答中的三个事实。

1. 问清家人如何记清单和最麻烦的一步。
2. 实现新增、删除、保存和导出。
3. 在手机与电脑检查实际操作。
4. 测试空输入、刷新与错误备份。
5. 请家人实际使用，记录一个改进并交付。

成果：可用网页、测试和一份改动说明。

### 用真实或明确标注的样例记录分析采购

调用技能：把一个问题写成可计算的数据定义、清理重复和缺失并保留原始数据、用查询按类别汇总一张表、选择一张不误导读者的图、检查一个数据结论能否成立、交付一份可以复算的短分析。

1. 先确定一个范围明确的问题。
2. 取得许可后使用去标识记录，或标明样例。
3. 保留原始表并清理异常。
4. 计算、制图并复核一个关键数字。
5. 交付一页结论和数据不足之处。

成果：原始与清理数据、查询、图表和可复算结论。

### 设计并测试一份阅读记录工具

调用技能：观察一次真实操作并记录卡点、画出从开始到结果的操作流程、做一份可以演示的纸面或点击原型、用三次观察修正同一个原型、检查文字、对比度与键盘操作、把设计交给另一人正确实现。

1. 观察一位愿意参与的人实际记录阅读。

3. 制作纸面或点击原型。
4. 用同一任务观察使用并修正。
5. 写清实现要求，检查实际结果。

成果：原型、观察记录、修订与实现说明。

### 改进一架纸直升机并解释证据

调用技能：把好奇变成可以试验的问题、用同一方法重复测量三次、照图制作一架纸直升机、只改一个条件比较两种设计、写出别人能复现的制作说明、用测试结果选择下一次改进。

1. 按来源模板制作基准模型。
2. 确定只改变的一个条件。
3. 对两种方案按同样方法各测三次。
4. 比较全部数据并保留失败结果。
5. 让另一人复现并展示下一轮改进。

成果：两个模型、六次原始测量和复现说明。

剪刀、释放高度和场地由成人确认。

### 教另一人学会一项生活小技能

调用技能：把教学目标写成能看见的表现、边示范边解释关键判断、设计三道从记住到应用的检查、给一条能立即使用的改进建议、换个情境检查是否真的会用、完成一次五分钟小教学并复盘、把购物袋口系牢。

1. 与对方确认愿意学哪项技能。
2. 写清完成标准并做简短示范。
3. 让对方自己做，观察困难。
4. 给一条可使用的改进建议。
5. 换个情境再试，并复盘教学。

成果：学习者的实际表现、帮助情况与教学反思。

### 办一次使用代币的模拟小集市

调用技能：为一个经营想法找三次真实问题、算清一件作品的直接成本、写一页可理解的产品说明、做一次可核对的库存记录、组织一次使用代币的模拟交易、用记录判断经营试验下一步。

1. 先了解参与者真实需要，再决定样品。
2. 列成本与库存，写清模拟规则。
3. 展示样品，让参与者自主选择。
4. 记录每笔代币交易和差错处理。
5. 核对数量与成本，决定下一轮改进。

成果：模拟交易记录、库存核对、成本和改进方案。
