## 当前优先顺序

1. 从原对话取回实际源码、核对线上后端，备份旧数据。
2. 完成手机、平板和电脑统一入口、账号与同步，验证离线、重复提交、冲突和账号隔离。
3. 完成生活、学习等分类以及小技能的完成标准和复习记录。

## 20 户家庭试验的指标假设

| 指标 | 验证目标 |
|---|---|
| 理解与开始 | 至少 16/20 户能选分类、找到技能并完成第一次练习记录 |
| 技能拆解 | 至少 12/20 户能把一个适合孩子的大技能拆为 3—7 项可检验的小技能 |
| 再次练习 | 至少 12/20 户对至少两项技能发生真实再次练习，展示间隔和情境 |
| 项目闭环 | 至少 10/20 户完成一个使用至少三项技能的真实项目，保留结果和复盘 |
| 孩子理解成果 | 完成项目的孩子能用自己的方式指出自己做了什么、用了哪些技能、哪里还要练 |
| 跨项目复用 | 有条件的家庭尝试把至少一项已有技能用于第二个情境；单列样本，不凑数量 |
| 真实购买 | 首轮至少 6/20 户实付完整价格年费；退款期内标暂定；按项目购买另行统计 |

以上是事先约定的探索门槛，不是教育效果标准；按孩子年龄、项目周期和实际资源在试验开始前修订。四周只够做小项目，未完成的大项目要记录进度和原因，不催促孩子制造成果。

退出和失联保留在原分母；家长观察、孩子说明、作品和程序操作分别标明来源。用过软件、练过一次、家长点过确认都不能自动等同于掌握。

## 核心决策

孩子只收金币却说不清学会什么：调整反馈与检验。

分类和拆解太复杂导致不会开始：简化结构并提供示例。

技能只停留在单独练习、不能用于项目：优先改项目设计与练习衔接。

真实项目能做成，但不需要持续订阅：测试项目包或买断方式。

出现家庭越权、重复记账、丢失或错误覆盖：先停止受影响流程，修复并复验。

下一次汇报应分别说明：多端同步做到哪一步；技能分类、拆解和项目应用哪些已实现；哪些结果有真实孩子使用证据。
