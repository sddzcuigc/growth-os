# 成长森林：把小本领用到真实生活里

核心目标是：让孩子学会、复习具体的小技能，逐步组成大能力，在真实项目里应用和检验，感受到“这是我做成的”。家长帮助示范、反馈和共同确认。

## 一条主线

**选一个小技能 → 看步骤并动手 → 隔一段时间再练 → 在项目里使用 → 留下结果与下一步。**

例如，“为家人准备午餐”不是一个笼统的打卡任务。它可以用到列采购清单、比较价格、挑选食材、系塑料袋、清洗和整理等小技能。每项技能都有具体操作、前置动作与完成标准。项目记录区分自己完成的部分、需要的帮助和下次要练的动作。

同一项小技能可以用于不同项目，复用同一个技能记录。加入计划、点击按钮、练习次数或领取奖励，都不等于已经独立掌握。

## 四个入口，各回答一个问题

| 入口 | 孩子的问题 | 页面内容 |
| --- | --- | --- |
| 今天 | 我现在可以做什么？ | 选小技能、今天练习、两个项目入口 |
| 技能 | 我想学什么，已经练过什么？ | 分类技能树、完整技能清单、具体路线与做法、自定义技能 |
| 项目 | 我能用这些本领做成什么？ | 八个项目、需要的技能、实际结果与复盘 |
| 成长 | 我做过什么，下次练什么？ | 本周小结、练习足迹；徽章、奖励与统计可展开 |

设置单独收纳账号同步、备份与技能管理、家庭确认、本周计划和安装。每一组按需展开；孩子的日常学习不需要穿过管理表单。

## 技能树的组织

通用基础包括生活自主、学习方法、数字与 AI 判断、日常判断、合作与身心照顾；职业路线用于好奇与探索，不作为给孩子过早定职业的要求。

技能必须具体到可以开始操作，例如“系一个能提起又能解开的袋口”，而不是“提高生活能力”。来源和步骤沿用现有 72 项技能库与 11 条路线；先示范、自己尝试、获得具体反馈、延后复习、换情境使用。

## 主题是呈现方式

V26 提供森林与方块世界两套主题。方块世界使用原创方块地形和七种树木矢量图，并改变卡片、按钮、节点和弹窗样式。主题保存在当前设备，刷新与离线均可用；技能、项目、练习和账号数据共用，不因换主题复制或重置。

主题切换不改变学习术语，不额外引入货币、任务系统或另一套导航。

## 本轮验收标准

首页只有三个主要区域，不再铺开全部树木与奖励；四个主入口在电脑和手机一致。360 像素手机首屏能看到“选个小技能”。旧功能都有明确位置，旧备份可继续练习并导出。

两套主题均验证资源加载、刷新记忆、离线切换以及不改变孩子记录。旧版的三端同步、队列、冲突、账号隔离和项目复用继续回归。实机与真实学习效果另行验证，不能用点击量代替成长。
