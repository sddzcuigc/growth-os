# 成长森林：产品计划与目标（修正版）

日期：2026-10-20。v2 根据本轮产品方向纠正，取代 v1 的目标、核心指标和首轮场景选择。历史版本保留供对照。

**产品目标：让孩子通过学习和复习不同的小技能，逐步掌握更大的能力；把大技能拆成可练习的小技能，把真实项目作为应用、检验和组合技能的土壤，让孩子看见自己做成了什么并获得成就感。**

技能可以按生活、学习、表达、运动、创造等分类。“买菜”“系塑料袋”“做一道菜”都可以作为技能记录。大小取决于孩子的基础和当前练习范围；系统不把某个技能永久限定为最小单位。

例子：生活类的“做番茄炒蛋”可以继续拆成辨认食材、采购、处理食材、烹饪和清理；“为家人准备一顿午餐”是一次实际项目，调用这些技能，也可能调用预算、阅读、表达等学习类技能。做完以后保留结果和复盘，知道哪些会了、哪些仍需练习。

分类用于寻找；拆解用于练习；项目用于实际应用与检验；成就来自孩子真实做成的事情。家长是示范、陪练、观察和共同复盘者。

| 优先级 | 工作 | 目标 |
|---|---|---|
| 第一件事 | 各终端与数据同步 | 手机、平板、电脑共用账号和记录；断网不丢，冲突不悄悄覆盖 |
| 下一阶段 | 技能分类与拆解 | 可以组织生活、学习等技能，组合大技能，并复用已有小技能 |
| 随后 | 项目练习与作品 | 一个项目关联多项技能，记录应用过程、完成结果与复盘 |
| 之后 | 成长呈现与商业验证 | 孩子能说清自己学会了什么、在哪里用过；家庭愿意持续使用和付费 |
