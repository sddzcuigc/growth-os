# 产品目标与路线

## 产品目标

围绕孩子的实际能力成长，建立“选想做的事情 → 拆出需要的技能 → 学习与练习 → 隔一段时间复习 → 在真实项目中组合应用 → 查看结果并复盘 → 获得成就感”的循环。

产品成功首先看孩子是否学会、复习和应用技能，是否做出了真实结果。家长操作方便是可用性要求；记录次数、树高、金币、打开次数都是辅助数据。

## 技能的组织方式

| 概念 | 含义 | 例子 |
|---|---|---|
| 分类 | 用于寻找与整理技能，可调整 | 生活类、学习类、表达类、运动类、创造类 |
| 小技能 | 适合当前孩子独立练习和检验的一项动作 | 系塑料袋、按清单买菜、看懂单价、查一个资料来源 |
| 大技能 | 可以继续拆解、需要组合多项技能的能力 | 独立做一道菜、制作一份资料介绍、完成一次小采购 |
| 项目 | 有具体目标、过程和结果的一次真实实践 | 为家人准备周末午餐、做一本植物观察册 |
| 练习与复习 | 围绕一项技能的真实尝试与再次使用 | 今天练一次系袋口，下周再次用于实际采购 |
| 项目检验 | 看孩子是否能把技能用于当下情境 | 采购时是否自己选菜、比较价格、整理和系好袋子 |

技能可以进一步拆解，也可以被多个大技能、多个项目引用。复用同一技能 ID 和历史记录，避免每次建项目都重新创建“买菜”或“系塑料袋”。分类不限制项目跨领域组合。

## 一次完整体验

孩子想“为家人做一顿午餐”。孩子与家长确定适合年龄和条件的项目范围，选一道菜，拆出采购、处理食材、烹饪、清理等环节；从已有技能里选择或补建需要练的技能。

先学不熟悉的步骤，记录如何练习和需要什么帮助。实际做午餐时关联使用过的技能，留下做成的菜、采购清单或其他合适的结果。孩子用自己的话说“我这次自己做了什么、哪里还不会、下次想怎样试”。

完成后项目可以开花或获得纪念卡。技能的掌握描述来自实际观察和应用记录，练习次数不能自动等同于能力等级。安全相关步骤根据孩子情况由成人指导，记录如实区分自己完成和成人代做。

## 设计、技术、产品与网站

| 方向 | 主要工作 |
|---|---|
| 设计 | 技能分类清楚；能看懂大小技能关系；项目展示自己做成的事情；森林变化与真实记录相连 |
| 技术 | 先完成各终端共用数据；保持技能 ID、引用、练习、项目和作品记录一致，保留历史与冲突 |
| 产品力 | 提供可调整的拆解示例、练习方法、复习安排、项目脚手架和复盘方式，让技能能真正用起来 |
| 宣传网站 | 用一道菜或一次采购讲清整个过程，真实展示拆解、练习、应用和成果 |

## 阶段目标

90 天日历仍暂按 2026-10-21 至 2027-01-18；先核对源码与实际工期，不能为赶日期省略验收。

| 阶段 | 交付 | 验收重点 |
|---|---|---|
| 第一项：多端同步 | 原项目恢复、统一账号与云端、自动同步、离线队列、冲突保留、安装入口 | 三个独立设备环境看到相同技能和练习；服务重启后仍在 |
| D1—D14：方向与结构 | 5 组孩子及家长访谈、分类与拆解原型、一条真实项目路径 | 孩子能解释目标和下一项练习，家长能说明如何检验 |
| D15—D35：最小闭环 | 分类技能、大技能引用、练习复习、项目关联与复盘、首版官网 | 一个孩子实际从小技能练习走到项目结果 |
| D36—D70：家庭试验 | 20 户家庭，记录基线和四周使用；按实际项目节奏执行 | 看完成的技能与项目，不要求每天打卡 |
| D71—D90：修正与收费 | 修复主要中断点，测试完整价格购买与招募渠道 | 有真实结果、持续需求和付款，再扩大投入 |

首轮内容先做生活与学习两类、约 20 项可组合技能、3 个可调整的大技能和 2 个项目模板。数量是准备范围，不能作为用户已经掌握的成绩。

## 商业目标

仍保留 299 元/家庭/年作为价格假设，四周体验是否采用 39 元须在明确内容后验证。价值来自技能练习、可复用项目内容与长期成长记录。

90 天冲刺 50 户净年费家庭，6 个月 300 户，12 个月累计 3,345 笔 299 元净年费订单，销售收款约 100 万元。优惠按实收、退款扣除，人工与运营成本另记。它们是条件目标，不是估值、利润或销量预测。

如果家庭主要为一个项目付费，应比较按项目购买或买断方式；如果多次主动开展新项目，才进一步验证订阅价值。不能为了提高使用时长而推迟技能掌握或项目完成。

90 天新增现金预算建议上限仍为 2 万元，不含人员工资及外包开发；分阶段启用。前版以“减少催促”作为付费核心的判断撤回。
