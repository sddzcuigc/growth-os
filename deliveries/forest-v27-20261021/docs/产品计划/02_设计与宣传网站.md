# 设计与宣传网站

## 界面主线

孩子首页突出“我想做什么、我正在练什么、我已经做成什么”。技能森林按生活、学习等类别组织，项目入口可以调出跨分类技能。家长提供示范、帮助与观察，操作不占据孩子主体验。

| 页面 | 重点 |
|---|---|
| 我的技能 | 分类寻找；学过、练过、在哪个项目用过；支持复习 |
| 大技能 | 显示组成的小技能和当前练习步骤，可继续拆解 |
| 我的项目 | 展示具体目标、需要的技能、实际过程和结果 |
| 一次练习 | 看完成标准、最小步骤，记录尝试、帮助和困难 |
| 项目成果 | 作品或结果、孩子自己的说明、下次改进 |
| 我的森林 | 从真实练习与项目经历生成可理解的成长反馈 |

视觉保持温暖绘本森林。儿童字大、操作清楚、一次聚焦一项行动；手机和平板都可用。先做一套主树与成长状态，验证后再扩展树种。树高和金币是表现形式，不作为能力测量。

技能成长可以展示“提示下完成、自己完成、换个情境会用、能组合做项目、能讲给别人”。这些是可记录的观察方式，不能仅按复习次数自动升档，也不能把没有观察当成不会。

## 官网主张草案

主标题：把想做的大事，变成孩子一步步学会的小技能。

副标题：从买菜、系塑料袋、做一道菜开始。分类积累技能，拆开练习、持续复习，再用真实项目把它们用起来，让孩子看见自己做成了什么。

页面顺序：产品画面与主张 → 一个完整项目 → 如何拆技能 → 怎么练习和复习 → 项目里如何应用与检验 → 孩子的成果 → 多端同步说明 → 价格与常见问题 → 开始入口。

核心演示：“为家人准备一顿午餐”。展示选项目、调用生活及学习技能、记录练习、实际做成、回看成果。没有真实家庭验证前标注为操作样例；不编造作品、改善百分比或家长评价。

首轮主按钮在未开放时写“申请家庭试用”，实际开放后写“开始我的技能森林”。说明共享设备与安装方法、数据同步、作品资料处理和费用。

## 验收

5 组孩子及家长中至少 4 组能说明技能分类、大技能与项目分别做什么，找到当前练习并看懂已完成记录。由孩子描述自己在项目里用了哪些技能，避免只有家长看懂。

官网邀请 5 名新用户看完后复述产品用途，至少 4 人能讲清“技能学习与复习、拆解、项目应用、成果反馈”中的主要过程。
