# 成长森林 V23：多端同步与具体技能路线

产品目标：把大能力拆成可以练习的小技能，用真实项目组合、复习和检验，让孩子看见自己做成了什么。

本次交付包含 72 项具体技能、11 个分类、5 条通用基础路线、6 条职业探索路线及 8 个项目。每项技能有准备材料、前置动作、至少五步操作、完成条件、复习办法和来源。打开“选择技能路线”可查看、加入技能树、开始项目并保存实际结果与复盘。

手机、平板和电脑使用同一套 Web/PWA 界面；浏览器支持时可以安装到主屏幕。登录同一账号或通过家庭邀请码加入后共用记录。离线先保存，重连补传；不能安全合并的修改保留双方副本。原生 Tauri 工程保留，安装包未纳入本次已验证交付。

## 本地运行

需要 Node 22.13 以上；云端推荐 Node 24。

```powershell
npm ci
npm run dev
```

本地真实登录仍须配置已授权的 Firebase 域名和持久化数据库。本地演示和测试请显式运行 `npm run dev:local`，仅监听本机回环地址。测试身份在 Vercel 环境强制关闭。

```powershell
npm run build:library
npm run validate
npm run test:sync
npm run test:atomic
npm run test:roadmap
npm run test:multi-device
npm run build:web
```

最后一项浏览器测试使用本机已安装的 Microsoft Edge。测试中的手机、平板为隔离浏览器上下文与屏幕模拟；不是实机认证。测试创建临时 SQLite，完成后清理。

## 使用边界

本内容是参考公开教育框架、职业任务、官方操作指南和研究方法编写的第一版练习卡。职业路线用于兴趣探索与入门，不是完整职业培养或执业资格课程。没有任何单一方法适合所有人；按实际困难调整示范、练习和复习。

加入技能树不发奖励，也不代表已掌握。项目结果与复盘标为自述记录。旧版铜银金果实仍按练习次数显示，暂不作为独立能力测评；旧版预设人物和成长数字是原项目示例，不能当成新用户的学习事实。

源码保留原有 Firebase 公共客户端配置；没有打包数据库、服务端密钥或账号凭证。部署所需变量见同步说明。
