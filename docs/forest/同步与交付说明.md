# V27 同步与交付说明

2026-10-21。本轮升级界面和本地静态资源；服务端、数据库结构与协议继续沿用 V23，不迁移或重置孩子记录。

## 本轮实际验证

- 三份隔离浏览器上下文读取同一家庭记录；当前孩子视图各设备独立。
- 一端新增技能，其他端自动看到；离线练习重开后保留，联网补传。
- 重复确认不重复奖励；同一事实冲突保留双方；切换账号不串记录。
- 技能操作卡、项目的技能引用、实际结果与复盘可以同步；离线可查阅完整技能库。
- 1440、820、390、360 像素布局没有横向溢出，图片与样式加载正常。
- 技能和路线对话框支持键盘焦点与 Escape；主要操作按钮检查文字对比度。
- 新项目摘要对用户文字转义，旧形状数据不会破坏首页，也不修改原记录。
- 生产静态处理器可提供全部离线壳资源、CSS 和模块的正确 MIME，并拒绝访问私有路径。

证据：[三端同步](../../deliveries/forest-v27-20261021/evidence/browser-multi-device.json)、[路线与项目](../../deliveries/forest-v27-20261021/evidence/browser-roadmap.json)、[视觉与交互](../../deliveries/forest-v27-20261021/evidence/visual-design.json)、[离线总览](../../deliveries/forest-v27-20261021/evidence/overview.json)。手机和平板是 Edge/Chromium 的视口与触控模拟，不是实机认证。使用显式本地测试身份和真实 HTTP/SQLite，未将其当作生产登录验收。

## 源码与部署

现有仓库：[sddzcuigc/growth-os](https://github.com/sddzcuigc/growth-os)。继续使用分支 `codex/forest-v23-skill-routes` 与 [草稿 PR #11](https://github.com/sddzcuigc/growth-os/pull/11)。前端在 `forest/`；独立同步接口保留；现有 GrowthOS 根应用保留。

Vercel 从 Git 分支自动创建预览。正式网站仍需进一步明确授权；不通过定时任务发布生产、合并主分支或创建受保护预览的临时访问链接。预览 READY 仅表示构建完成，不能替代生产账号和真实云库往返验收。

云端所需变量仍为 `TURSO_DATABASE_URL`/`LIBSQL_URL` 与对应服务端 token，可选 `FIREBASE_PROJECT_ID`。线上没有持久化数据库则拒绝启动；本地测试身份在线上强制禁用。工程包不包含这些服务端密钥。
