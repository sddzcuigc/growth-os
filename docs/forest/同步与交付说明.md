# 同步与交付说明

## 已实现并在本地验证

- 桌面、手机和平板三份隔离浏览器上下文自动交换同一家庭记录。
- 当前查看的孩子保留在各设备本地，不因另一设备切换孩子而改变。
- 离线练习先保存到账号队列，重开页面后保留；联网发送相同事件编号，重复确认不会重复奖励。
- 不同字段的修改可以合并；同一事实存在冲突时保存双方副本，暂停覆盖。
- 切换账号隔离成长记录、同步基线与待上传事件。
- 成长数据、练习提交、奖励和历史版本通过数据库事务一起提交或回滚。
- 技能卡和项目可以离线查阅；导入模板不发奖励、不标记掌握。

证据见 evidence 下 JSON 和编号 01–09 截图。手机和平板测试是 Chromium/Edge 屏幕与触控模拟，未等同于 Android/iPad 实机测试。测试使用显式本地身份，未冒充生产账号验收。

## 云端接入

保留已有 GrowthOS 网站，在 `/forest/` 增加成长森林；新的 `/api/forest-sync`、`/api/forest-health` 使用同一个持久化数据库。原应用与原有同步入口保留。新旧客户端的同步协议不同，后续使用新入口，旧客户端的新修改不会反向持续迁入。

首次使用会查找该账号旧记录并迁入家庭空间；不是跨账号查找或公开旧数据。家庭邀请是单次、限时凭证；账号凭证只保存在身份服务与当前会话。

服务端变量：`TURSO_DATABASE_URL` 或 `LIBSQL_URL`；`TURSO_AUTH_TOKEN` 或 `LIBSQL_AUTH_TOKEN`；可选 `FIREBASE_PROJECT_ID`。线上缺少持久化数据库时拒绝启动，不退化为临时磁盘假同步。`ALLOW_DEV_AUTH` 在线上强制无效。

## 当前边界

源代码草稿：[GitHub PR #11](https://github.com/sddzcuigc/growth-os/pull/11)。分支触发的独立预览已经构建，但受 Vercel 登录保护。生产网站尚未更新。自动审批拒绝了未明确目标的部署请求，以及创建临时认证访问链接的请求；上线与受保护预览的访问验证仍需获得授权。

原生 Windows/macOS/Linux/Android/iOS 安装包未验证或交付。当前统一入口为浏览器/PWA；安装体验取决于实际浏览器。iOS 原生编译需要 macOS 和 Xcode。

生产 Firebase 登录和真实家庭的多设备同步须以正常授权账号实际验收，本地开发身份通过不能替代这一项。技能卡是第一版练习设计，尚未完成真实儿童教学效果验证。旧版预设人物、数字和按次数显示的果实等级保留，不能当作能力测评。
